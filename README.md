# Orb Collector

مشروع تدريبي لقراءة رقم الـOrbs من لقطات الشاشة باستخدام OCR.

## المرحلة الحالية

- تحليل Screenshot موجودة.
- قص منطقة رقم الـOrbs.
- تحسين الصورة باستخدام Pillow.
- استخراج الرقم بواسطة Tesseract.
- مقارنة القراءة الحالية بالقراءة السابقة.

> هذا المشروع لا ينفذ النقر أو جمع المكافآت تلقائيًا.

## البيئة

- Android / Termux
- Python
- Pillow
- Tesseract OCR
